# PyPanel

Лёгкая веб-панель для хостинга своих Python-проектов на VPS. Загрузили проект, нажали «Запуск», и он работает 24/7: упал, значит панель сама его поднимет.

Один файл (`app.py`), только Flask и gunicorn, никаких баз данных и Docker. Все проекты используют **один общий venv**, поэтому библиотеки ставятся один раз.

## Возможности

- **Проект = папка.** Можно загрузить несколько файлов, целую папку с вложенными папками или один `.zip`.
- **Запуск, остановка, перезапуск** одной кнопкой. Работает и для простых скриптов и ботов, и для Flask/FastAPI-приложений.
- **Аптайм.** Сторож каждые 2 секунды проверяет проекты и перезапускает упавшие (при частых падениях пауза растёт до 60 секунд). Список проектов, которые должны работать, хранится на диске, поэтому после перезагрузки VPS они поднимаются сами.
- **Общий venv.** Установка пакетов из браузера: вручную или из `requirements.txt` проекта.
- **Файловый менеджер:** навигация по папкам, загрузка файлов и папок, создание, редактирование текстовых файлов, скачивание, удаление.
- **Логи** каждого проекта в реальном времени, переменные окружения, своя команда запуска.
- Порт для каждого проекта выдаётся автоматически (с 9001).
- Вход по паролю, светлая и тёмная тема, адаптивный интерфейс.

## Установка одной командой

На чистом VPS (Debian/Ubuntu, также RHEL-подобные системы с systemd), от root:

```bash
curl -fsSL https://raw.githubusercontent.com/dobrozor/PyPanelScript/main/install.sh | sudo bash
```

Скрипт поставит `python3`/`venv` (если их нет), создаст venv в `/opt/pypanel`, сгенерирует пароль, зарегистрирует systemd-сервис, откроет порт в `ufw` (если он включён) и выведет адрес панели и пароль.

Свои параметры задаются переменными:

```bash
curl -fsSL https://raw.githubusercontent.com/dobrozor/PyPanelScript/main/install.sh \
  | sudo PANEL_PASSWORD='мой_пароль' PANEL_PORT=8001 PANEL_HOST=0.0.0.0 bash
```

| Переменная | По умолчанию | Описание |
|---|---|---|
| `PANEL_PASSWORD` | случайный | Пароль входа (без символа `'`) |
| `PANEL_PORT` | `8001` | Порт панели |
| `PANEL_HOST` | `0.0.0.0` | Адрес: `0.0.0.0` для доступа извне, `127.0.0.1` только для локального/прокси |
| `PYPANEL_DIR` | `/opt/pypanel` | Куда ставить |

Настройки хранятся в `/etc/pypanel.env`. После их изменения: `systemctl restart pypanel`.

### Обновление и удаление

```bash
# обновить (проекты и данные не затрагиваются)
curl -fsSL https://raw.githubusercontent.com/dobrozor/PyPanelScript/main/install.sh | sudo bash -s update

# удалить сервис (проекты останутся в /opt/pypanel/data)
curl -fsSL https://raw.githubusercontent.com/dobrozor/PyPanelScript/main/install.sh | sudo bash -s uninstall

# удалить всё, включая проекты
curl -fsSL https://raw.githubusercontent.com/dobrozor/PyPanelScript/main/install.sh | sudo bash -s uninstall --purge
```

## Как пользоваться

1. Откройте `http://IP_ВПС:8001` и войдите по паролю.
2. **Пакеты (pip)**: поставьте нужные библиотеки в общий venv (`flask requests gunicorn aiogram` и т. д.).
3. **Новый проект**: введите имя и загрузите файлы, папку или `.zip`.
4. Нажмите **Запуск**. Логи доступны по кнопке «Логи», файлы по кнопке «Файлы».

### Команда запуска

По умолчанию панель ищет `main.py`, `app.py`, `bot.py` или `run.py` в корне проекта. Команду можно изменить в «Настройках». В ней доступны:

- `{python}`: python из общего venv;
- `{port}`: порт проекта (он же передаётся в переменной окружения `PORT`).

Примеры:

```text
{python} main.py
{python} src/bot.py
gunicorn -w 2 -b 127.0.0.1:{port} app:app          # Flask
uvicorn main:app --host 127.0.0.1 --port {port}      # FastAPI (pip install uvicorn)
```

Команды `gunicorn`, `uvicorn` и другие ищутся в общем venv автоматически.

### Домен и HTTPS для проектов

Порт проекта можно отдавать наружу через Caddy или nginx. Пример Caddyfile:

```text
panel.example.com {
    reverse_proxy 127.0.0.1:8001
}

mysite.example.com {
    reverse_proxy 127.0.0.1:9001
}
```

Если панель стоит за прокси, поставьте `PANEL_HOST=127.0.0.1` в `/etc/pypanel.env` и перезапустите сервис.

## Безопасность

Панель по сути даёт запуск произвольного кода на сервере, поэтому относитесь к ней как к SSH-доступу.

- Используйте длинный пароль. Без HTTPS он передаётся открытым текстом: поставьте панель за Caddy/nginx с сертификатом или ходите через SSH-туннель (`ssh -L 8001:127.0.0.1:8001 user@vps` при `PANEL_HOST=127.0.0.1`).
- По возможности ограничьте доступ по IP: `ufw allow from ВАШ_IP to any port 8001`.
- Проекты запускаются от того же пользователя, что и панель (по умолчанию root), и не изолированы друг от друга. Не запускайте чужой недоверенный код.

## Как это устроено

```text
/opt/pypanel/
├── app.py              # вся панель
├── venv/               # общий venv для панели и всех проектов
└── data/
    ├── meta.json       # список проектов, команды, порты, состояние «запущен/остановлен»
    ├── projects/<имя>/ # папка каждого проекта
    └── logs/<имя>.log  # логи (обрезаются, когда превышают 5 МБ)
```

- Панель работает в **одном процессе** gunicorn (`-w 1`): состояние процессов хранится в памяти, поэтому воркеров должно быть ровно один.
- Каждый проект запускается в отдельной группе процессов, при остановке завершается вся группа.
- При перезапуске самой панели проекты останавливаются и сразу поднимаются снова.
- Файлы проекта в `data/projects/` панель никогда не очищает: повторная загрузка только перезаписывает файлы с совпадающими именами. Базы данных и конфиги внутри папки проекта сохраняются.

## Ограничения

- Нет изоляции проектов и ограничений по памяти/CPU.
- Нет отдельных venv: конфликты версий библиотек между проектами нужно разруливать самим.
- Один пользователь и один пароль.
- Редактор открывает только текстовые файлы до 1 МБ, загрузка ограничена 200 МБ за раз.
